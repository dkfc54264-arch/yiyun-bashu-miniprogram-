# 艺韵巴蜀 · 沉浸式数字研学基地

> 一款基于微信云开发的沉浸式非遗数字研学小程序，扎根重庆酉阳龚滩古镇的真实场景。小程序以剧情闯关为主线，融合五大非遗关卡答题、沉浸式电子剧本、3D数字展馆（巴小艺IP形象、剪纸三维展示、科普视频）、AI智能讲解员、积分排行、研学报告与文创商城等功能，让青少年在「故事探索+文化解密」中读懂非遗，实现传统文化的年轻化传播与数字化传承。

## 功能模块

| 模块 | 说明 |
|---|---|
| 预约购票 | 三版本剧本（亲子/进阶/沉浸）选场次购票，生成电子门票 |
| 关卡任务 | 五大非遗关卡：阅读知识卡 → 答题闯关 → 得积分、解锁文化线索 |
| 电子剧本 | 《酉阳秘境·非遗守护人》三版本章节式沉浸故事 |
| 数字展馆 | 巴小艺 IP 人设 3D 旋转展示、剪纸 3D 模型、非遗科普视频 |
| AI 巴小艺 | 智能问答（云函数接 GLM，含关键词降级兜底） |
| 积分排行 | 守护人积分榜，实时名次 |
| 研学报告 | 多板块心得撰写、报告生成与分享（分享得积分） |
| 文创商城 | 非遗好物积分兑换，扣减积分与库存 |

## 技术栈

- **前端**：微信小程序原生（WXML/WXSS/JS），自定义 tabBar，黛山朱砂新中式设计体系
- **后端**：微信云开发（云函数 + 云数据库）
- **AI**：智谱 GLM-4-Flash（云函数内调用，密钥存云端环境变量）

## 目录结构

```
├── miniprogram/            # 小程序前端
│   ├── pages/              # 首页/研学/展馆/我的/预约/AI/排行/报告/商城
│   ├── custom-tab-bar/     # 自定义底部导航
│   ├── components/         # 公共组件（弹层等）
│   ├── data/               # 本地数据（关卡/剧本/视频）
│   ├── utils/              # 请求封装
│   └── images/             # 图片资源
├── cloudfunctions/         # 云函数：user / biz / aiChat
└── .trae/documents/        # 项目规划与模块架构文档
```

## 云资源

- 云数据库集合：`users` / `sessions` / `bookings` / `user_tasks` / `reports` / `products`
- 云函数：`user`（登录/资料/积分）、`biz`（业务路由：场次/订单/答题/排行/商城等）、`aiChat`（AI 问答）

## 快速开始

1. 微信开发者工具导入本项目
2. 开通云开发，部署 `cloudfunctions/` 下三个云函数
3. 创建数据库集合并导入场次/商品种子数据（见 `.trae/documents/` 实施文档附录）
4. 编译运行
